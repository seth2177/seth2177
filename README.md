# Seth Turnbo

Imaging systems and integration engineer. Twenty-three years on MRI and CT across GE, Philips and Siemens, from RF, gradients and reconstruction through DICOM, HL7, PACS/RIS and the hospital network. I connect imaging AI to real clinical sites.

**How I build.** I design tools from problems I have hit in the field, build them with modern AI-assisted development, and verify them with tests and adversarial checks before anything touches a site. Synthetic data only; no customer names.

## Projects

**[dicom-ai-router](https://github.com/seth2177/dicom-ai-router)** - DICOM router for imaging AI: receives studies by C-STORE, routes by rules, de-identifies (PS3.15 subset), calls the model, returns a Basic Text SR and key image to PACS. PHI audit included.

**[hl7v2-fhir-bridge](https://github.com/seth2177/hl7v2-fhir-bridge)** - HL7 v2 to FHIR R4 for the radiology workflow: ADT, orders and results over MLLP become validated, idempotent FHIR transaction bundles with provenance and actionable ACKs.

**[llm-eval-radiology](https://github.com/seth2177/llm-eval-radiology)** - When an AI-drafted radiology report is wrong, was it the detector or the LLM? Scores both against ground truth and attributes each error.
